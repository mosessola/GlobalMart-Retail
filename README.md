# 🛒 GlobalMart Retail Analytics

## 📌 Project Overview

GlobalMart Retail Analytics is an enterprise-scale data analytics project built using **Python, SQL, and Power BI**. The project analyzes over **10.5 million retail records** to assess data quality, validate business metrics, and generate insights for business decision-making.

> **Note:** The original datasets are not included in this repository due to their large size.

---

## 📊 Dataset Overview

| Dataset | Rows | Columns |
|---------|---------:|--------:|
| Customers | 1,000,000 | 11 |
| Orders | 4,000,000 | 15 |
| Inventory | 1,500,000 | 10 |
| Forecast | 2,000,000 | 7 |
| Shipments | 2,000,000 | 10 |
| Products | 20,000 | 9 |
| Stores | 650 | 9 |
| Suppliers | 600 | 7 |
